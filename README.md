## ✏️ Hướng Dẫn Tùy Chỉnh Thông Tin Cho Lớp Của Bạn

Mọi dữ liệu của website đều được tổ chức gọn gàng và dễ hiểu trong file **`js/data.js`**:

- **Đổi tên lớp, niên khóa, trường học:** Mở `js/data.js`, sửa ở phần `info: { className: "12A1", ... }`.
- **Đổi thông tin Cô/Thầy Chủ Nhiệm:** Sửa ở phần `teacher: { name: "...", avatar: "...", message: "..." }`.
- **Thêm/Sửa thành viên trong lớp:** Tìm đến mảng `students: [ ... ]`, copy thêm một phần tử hoặc sửa họ tên, biệt danh, ảnh đại diện, danh hiệu vui nhộn và ước mơ của các bạn.
- **Thay đổi link ảnh:** Bạn có thể copy ảnh thật của lớp vào thư mục `assets/` rồi điền đường dẫn ảnh (ví dụ: `assets/anh-tap-the.jpg`) vào file `js/data.js`.

## 🌐 Cách Đưa Website Lên Mạng Để Chia Sẻ Miễn Phí Cho Cả Lớp

Để mọi người trong lớp có thể mở bằng điện thoại hoặc máy tính ở bất kỳ đâu:

### Cách 1: Dùng Vercel hoặc Netlify (Khuyên dùng - Nhanh nhất)
1. Truy cập [app.netlify.com/drop](https://app.netlify.com/drop).
2. Kéo thả toàn bộ thư mục `ky-niem-12a1` vào trang web.
3. Sau 5 giây, Netlify sẽ tạo cho bạn một đường link miễn phí (ví dụ: `kyniem-12a1.netlify.app`) để bạn gửi vào nhóm Zalo/Messenger của lớp!

### Cách 2: Dùng GitHub Pages
1. Tạo một repository mới trên GitHub (ví dụ: `ky-niem-12a1`).
2. Tải toàn bộ file trong thư mục này lên GitHub.
3. Vào phần **Settings** > **Pages** > Chọn branch `main` và ấn **Save**. Trang web sẽ hoạt động ngay lập tức.
